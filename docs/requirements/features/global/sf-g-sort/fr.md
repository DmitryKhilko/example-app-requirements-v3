# ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ {#fr}

Критерии приёмки проверяются на каждом списке, который подключает функциональность. Эталонная реализация —
справочник видов изделий (`GET /api/v1/product-types`, экран «Виды изделий», приставка `data-testid` `pt`) с
[тестовым набором][fixture].

## FR-G-SORT-001. Сортировка списка {#fr-g-sort-001 .collapsed}

- **Использует**: [SF-G-SORT][], [AR-001][]
- **Используется в**: [UI-G-SORT-001][], [FR-PT-LIST-003][]
- **Описание**: Операция списка упорядочивает записи по одному выбранному полю и направлению либо по порядку по
умолчанию.
- **Условие**: Пользователь вызывает операцию списка, которая подключает [SF-G-SORT][]; проверки [AR-001][]
пройдены.
- **Результат**:
    - Без параметра `sort_by` записи идут в порядке по умолчанию, который задаёт функциональность.
    - С `sort_by` записи упорядочены по указанному полю в направлении `sort_order`: `asc` (по умолчанию) или `desc`.
      Одновременно действует сортировка только по одному полю.
    - При равных значениях поля сортировки записи упорядочены по `created_at`, затем по `pk`, по возрастанию,
      независимо от направления; так одна запись не попадает на две страницы подряд.
    - Правила сравнения по типу поля:

| Тип поля | Как сравнивается |
| :--- | :--- |
| Строка | Без учёта регистра, по правилам русского алфавита; «Колье» раньше «Кольца» |
| Число | Как число |
| Дата и время | По времени |
| Логическое | По возрастанию сначала `false`, затем `true` |
| Перечисление | Как задаёт функциональность: по названию значения или по порядку значений |

- **Ошибки параметров** (ответ `400`, коды из [AR-001][]):

| Параметр | Проверка | Код в `details` |
| :--- | :--- | :--- |
| `sort_by` | Значение — поле из перечня функциональности | `INVALID_VALUE` |
| `sort_order` | Значение — `asc` или `desc` | `INVALID_VALUE` |
| `sort_order` | Параметр передан вместе с `sort_by` | `INVALID_COMBINATION` |

- **Схема**: определение `sort_order` — в `global/api/list.schema.json`; перечень `sort_by` — в схеме операции.

### Критерии приёмки (AC) {#fr-g-sort-001-ac .collapsed}

```gherkin
# language: ru
@FR-G-SORT-001 @SF-G-SORT
Функционал: Сортировка списка

  Предыстория:
    Дано в справочнике видов изделий записи из файла "PT.fixture.json"
    И аутентифицированный пользователь с правом просмотра списка

  Структура сценария: Направление по умолчанию — по возрастанию
    Когда он запрашивает "<операция>" с параметром "sort_by" = "<поле>"
    Тогда первая запись "items" — "<первая>"

    Примеры:
      | операция                  | поле            | первая   |
      | GET /api/v1/product-types | name_nominative | Браслеты |

  Структура сценария: Равные значения упорядочены по дате создания
    Когда он запрашивает "<операция>" с параметрами "sort_by" = "<поле>", "sort_order" = "desc", "page_size" = 25
    Тогда первые три записи — <первые>

    Примеры:
      | операция                  | поле                 | первые                       |
      | GET /api/v1/product-types | default_streak_count | "Браслеты", "Броши", "Колье" |

  Структура сценария: Порядок однозначен при переходе по страницам
    Когда он запрашивает страницы 1 и 2 "<операция>" с параметрами "sort_by" = "<поле>", "page_size" = 10
    Тогда ни одна запись не встречается на обеих страницах
    И вместе страницы содержат все <total> записей

    Примеры:
      | операция                  | поле                 | total |
      | GET /api/v1/product-types | default_streak_count | 15    |

  Структура сценария: Ошибка в параметре сортировки
    Когда он запрашивает "<операция>" с параметрами "<параметры>"
    Тогда код ответа равен 400
    И "details" содержит одну ошибку с полем "<поле>" и кодом "<код>"

    Примеры:
      | операция                  | параметры                             | поле       | код                 |
      | GET /api/v1/product-types | sort_by=color                         | sort_by    | INVALID_VALUE       |
      | GET /api/v1/product-types | sort_by=name_nominative&sort_order=up | sort_order | INVALID_VALUE       |
      | GET /api/v1/product-types | sort_order=desc                       | sort_order | INVALID_COMBINATION |
```
