## SF-G-SORT. Сортировка {#sf-g-sort .collapsed}

- **Статус**: анализ
- **Приоритет**: must
- **Стабильность**: высокая — цикл сортировки снят со скриншотов и закреплён в дизайн-системе
- **Права доступа**: определяет операция списка, которая подключает функциональность
- **Использует**: [AR-001][], [SF-G-PAG][], [дизайн-система][design-system] (DataTable)
- **Используется в**: [SF-PT-LIST][]
- **Описание**: Единые правила упорядочивания списков: параметры сортировки в API, правила сравнения значений,
однозначный порядок при равных значениях и сортировка по заголовку столбца таблицы.
- **Границы**:
    - **Входит**: Параметры `sort_by` и `sort_order`, сортировка по одному полю, дополнительный порядок, правила
      сравнения по типам данных, кнопка сортировки в заголовке столбца.
    - **Не входит**: Перечень сортируемых полей, порядок по умолчанию и сравнение перечислений — их задаёт
      функциональность, которая подключает сортировку; сортировка по нескольким полям сразу не используется.

### Состав требований {#sf-g-sort-content .collapsed}

| Требование | Что описывает |
| :--- | :--- |
| [FR-G-SORT-001][] | Сортировка списка (API) |
| [UI-G-SORT-001][] | Сортировка по заголовку столбца таблицы |

### Как подключить {#sf-g-sort-usage .collapsed}

Функциональность, которая подключает сортировку, указывает в своих требованиях:

- перечень полей, по которым разрешена сортировка (значения `sort_by`);
- порядок записей по умолчанию, когда сортировка не выбрана;
- правило сравнения для перечислений (по названию или по порядку значений);
- приставку `data-testid` экрана.
