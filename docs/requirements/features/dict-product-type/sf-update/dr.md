# ТРЕБОВАНИЯ К ДАННЫМ {#dr}

## DR-PT-UPDATE-001. Данные для изменения вида изделий {#dr-pt-update-001 .collapsed}

- **Использует**: [F-PT][], [DR-PT-001][]
- **Используется в**: [SF-PT-UPDATE][], [FR-PT-UPDATE-001][], [FR-PT-UPDATE-002][], [FR-PT-UPDATE-003][],
[AR-PT-UPDATE-001][], [UI-PT-001][]
- **Описание**: Состав данных запроса изменения записи справочника видов изделий (таблица `dict_product_type`):
какие поля передаёт пользователь, какие меняет система и как проверяется, что запись не изменили другие
пользователи.

### Данные, которые передаёт пользователь {#dr-pt-update-001-input .collapsed}

Идентификатор записи `pk` передаётся в пути запроса. Тело запроса содержит все изменяемые поля записи целиком
(полная замена); все поля обязательны.

| Поле | Тип | Ограничения | Описание |
| :--- | :--- | :--- | :--- |
| `name_nominative` | VARCHAR(150) | Как в [DR-PT-001][] | Наименование изделия |
| `product_group` | ENUM | Как в [DR-PT-001][] | Тип изделия |
| `default_streak_count` | DECIMAL(5,2) | Как в [DR-PT-001][] | Количество натиров (базовое) |
| `wholesale_gold_streak_count` | DECIMAL(5,2) | Как в [DR-PT-001][] | Натиры для золотых изделий (опт) |
| `stamp_impressions_count` | INT | Как в [DR-PT-001][] | Количество наложенных оттисков |
| `is_active` | BOOLEAN | `true` или `false` | Статус записи ([SF-PT-ACTIVATION][]) |
| `updated_at` | TIMESTAMP(0) | ISO 8601 в UTC, до секунды | Значение `updated_at` записи на момент чтения |

### Данные, которые меняет система {#dr-pt-update-001-system .collapsed}

| Поле | Значение после изменения |
| :--- | :--- |
| `pk` | Не меняется |
| `created_at` | Не меняется |
| `updated_at` | Дата и время изменения (UTC), если хотя бы одно значение изменилось; иначе не меняется (см. `H02`) |

### Ограничения {#dr-pt-update-001-constraints .collapsed}

- Уникальность — по правилу [DR-PT-001][]; сама изменяемая запись при проверке не учитывается.
- Проверка версии: `updated_at` из запроса совпадает с текущим `updated_at` записи с точностью до секунды
  ([DR-PT-001][]); иначе запись изменил другой пользователь, и изменение отклоняется по [FR-G-LOCK-001][].

### Допущения {#dr-pt-update-001-assumptions .collapsed}

- **DR-PT-UPDATE-001.H02**
    - **Статус**: требует подтверждения
    - **Подтверждает**: владелец справочника
    - **Допущение**: Запрос без изменений значений не меняет запись, `updated_at` и журнал аудита: «Изменено» в списке
      показывает дату последнего реального изменения.
