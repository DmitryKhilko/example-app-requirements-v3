# ТРЕБОВАНИЯ К ДАННЫМ {#dr}

## DR-PT-LIST-001. Данные списка видов изделий {#dr-pt-list-001 .collapsed}

- **Использует**: [F-PT][], [DR-PT-001][]
- **Используется в**: [SF-PT-LIST][], [FR-PT-LIST-001][], [FR-PT-LIST-002][], [FR-PT-LIST-003][],
[FR-PT-LIST-004][], [FR-PT-LIST-005][], [FR-PT-LIST-006][], [FR-PT-LIST-007][], [FR-PT-LIST-008][],
[FR-PT-LIST-009][], [AR-PT-LIST-001][]
- **Описание**: Состав записи списка видов изделий (таблица `dict_product_type`), поля, по которым разрешены поиск,
сортировка и фильтрация, и порядок записей по умолчанию. Размеры страницы — по [FR-G-PAG-001][].

### Поля записи списка {#dr-pt-list-001-fields .collapsed}

Запись списка содержит все поля сущности [DR-PT-001][] (типы и ограничения заданы там). Подпись — заголовок
столбца в таблице экрана.

| Поле | Подпись | Формат на экране |
| :--- | :--- | :--- |
| `pk` | Не показывается | Используется для выделения и открытия записи |
| `name_nominative` | Наименование | Текст как есть |
| `product_group` | Тип изделия | Название типа (см. ниже) |
| `default_streak_count` | Базовое кол-во натиров | Десятичное число (см. ниже) |
| `wholesale_gold_streak_count` | Кол-во натиров для золотых изделий оптовой торговли | То же |
| `stamp_impressions_count` | Кол-во наложенных оттисков | Целое число |
| `is_active` | Статус | Бейдж «ДЕЙСТВУЕТ» (`true`) или «НЕ ДЕЙСТВУЕТ» (`false`) |
| `created_at` | Создано | `ДД.ММ.ГГГГ ЧЧ:ММ:СС` |
| `updated_at` | Изменено | `ДД.ММ.ГГГГ ЧЧ:ММ:СС` |

Форматы:

- **Десятичное число**: разделитель — запятая, незначащие нули не показываются: `2`, `0,5`, `1,25`.
- **Дата и время**: по общим правилам [NFR-004][]: API передаёт UTC, экран показывает время часового пояса
  браузера пользователя.

### Значения `product_group` {#dr-pt-list-001-groups .collapsed}

Значения и их названия заданы в [DR-PT-001][]. В фильтре «Тип изделия» значения идут в порядке номеров из
[DR-PT-001][]; сортировка списка по типу изделия идёт по алфавиту названий (Весовые изделия, Часовые корпуса,
Ювелирные изделия), а не по коду и не по номеру.

### Поиск, сортировка и фильтрация {#dr-pt-list-001-capabilities .collapsed}

| Поле | Поиск | Сортировка | Фильтр | Условие фильтра |
| :--- | :--- | :--- | :--- | :--- |
| `name_nominative` | Да | Да | Да | Содержит подстроку без учёта регистра |
| `product_group` | Нет | Да | Да | Равно одному значению |
| `default_streak_count` | Нет | Да | Да | Равно числу |
| `wholesale_gold_streak_count` | Нет | Да | Да | Равно числу |
| `stamp_impressions_count` | Нет | Да | Да | Равно целому числу |
| `is_active` | Нет | Да | Да | Равно `true` или `false` |
| `created_at` | Нет | Да | Да | Входит в диапазон, границы включаются |
| `updated_at` | Нет | Да | Да | Входит в диапазон, границы включаются |

Правила сортировки:

- `product_group` — по названию типа, без учёта регистра, по правилам русского алфавита: по возрастанию
  «Весовые изделия», «Часовые корпуса», «Ювелирные изделия».
- `is_active` — по возрастанию сначала «Не действует» (`false`), затем «Действует» (`true`).

### Порядок записей {#dr-pt-list-001-paging .collapsed}

| Параметр | Значение |
| :--- | :--- |
| Порядок по умолчанию (сортировка не выбрана) | `created_at` по возрастанию, затем `pk` по возрастанию |
| Дополнительный порядок при выбранной сортировке | При равных значениях: `created_at` по возрастанию, затем `pk` |
| Максимальная длина строки поиска и фильтра по наименованию | 150 символов (как у `name_nominative`) |

Дополнительный порядок делает выдачу однозначной ([FR-G-SORT-001][]). Номер и размер страницы, допустимые размеры и
значения по умолчанию — по [FR-G-PAG-001][].

### Индексы {#dr-pt-list-001-indexes .collapsed}

Индексы, на которых держится показатель времени ответа [FR-PT-LIST-001][], заданы в [DR-PT-001][].

### Допущения {#dr-pt-list-001-assumptions .collapsed}

Допущение о размерах страницы перенесено в [FR-G-PAG-001][] (`FR-G-PAG-001.H01`).
