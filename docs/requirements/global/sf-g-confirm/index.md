## SF-G-CONFIRM. Подтверждение необратимого действия {#sf-g-confirm .collapsed}

- **Статус**: анализ
- **Приоритет**: must
- **Стабильность**: средняя — не подтверждён фокус на «Отмена» при открытии окна (`UI-G-CONFIRM-001.H01`)
- **Права доступа**: определяет действие, которое подтверждается
- **Использует**: [SF-G-TOAST][], [SF-G-SESSION][], [NFR-002][], [NFR-005][], [дизайн-система][design-system]
(Modal, Button)
- **Используется в**: [SF-PT-DELETE][]
- **Описание**: Перед необратимым действием (удалением) система показывает окно подтверждения с числом записей и
выполняет действие только после явного согласия.
- **Границы**:
    - **Входит**: Окно подтверждения, отмена, состояние отправки, закрытие окна по результату, защита от повторной
      отправки, доступность.
    - **Не входит**: Само действие, его API и тексты окна и уведомлений — их задаёт функциональность; подтверждение
      закрытия формы с несохранёнными данными (вопрос `UI-G-FORM-001.Q01`).

### Состав требований {#sf-g-confirm-content .collapsed}

| Требование | Что описывает |
| :--- | :--- |
| [UI-G-CONFIRM-001][] | Окно подтверждения |

### Как подключить {#sf-g-confirm-usage .collapsed}

Функциональность указывает: действие (часть `data-testid` `<p>-<действие>-modal`), элемент, который открывает окно,
заголовок-вопрос, текст с числом записей, подпись кнопки подтверждения, запрос и уведомления по ответам.
