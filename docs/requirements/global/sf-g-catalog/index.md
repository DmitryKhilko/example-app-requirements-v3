## SF-G-CATALOG. Каталог справочников {#sf-g-catalog .collapsed}

- **Статус**: анализ
- **Приоритет**: must
- **Стабильность**: низкая — источник перечня справочников, видимость недоступных справочников и поведение
  навигации не подтверждены (`UI-G-CATALOG-001.H01`…`H03`)
- **Права доступа**: экран видят все аутентифицированные пользователи; справочник показывается, если у
  пользователя есть право его просмотра (см. `UI-G-CATALOG-001.H02`)
- **Использует**: [SF-G-SEARCH][], [NFR-002][], [NFR-005][], [дизайн-система][design-system] (ListCard, NavCard,
TextInput)
- **Используется в**: [F-PT][] (вход в справочник видов изделий), [SF-G-DICT][]
- **Описание**: Экран «Справочники» собирает все справочники продукта по группам, позволяет найти справочник по
названию или описанию и перейти в него.
- **Границы**:
    - **Входит**: Группы и пункты справочников, переход в справочник, поиск по названию и описанию, навигация по
      группам со счётчиками.
    - **Не входит**: Экраны самих справочников ([SF-G-DICT][]); управление составом каталога из интерфейса.

### Состав требований {#sf-g-catalog-content .collapsed}

| Требование | Что описывает |
| :--- | :--- |
| [UI-G-CATALOG-001][] | Экран каталога справочников |

### Как подключить {#sf-g-catalog-usage .collapsed}

Справочник добавляется в каталог строкой перечня: группа, название, описание (одно предложение о содержимом),
адрес экрана и идентификатор для `data-testid` `dict-catalog-item-<справочник>` (у видов изделий —
`product-type`).
