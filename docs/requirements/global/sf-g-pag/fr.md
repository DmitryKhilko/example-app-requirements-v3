# ФУНКЦИОНАЛЬНЫЕ ТРЕБОВАНИЯ {#fr}

Критерии приёмки глобальной функциональности проверяются на каждом списке, который её подключает. Эталонная
реализация — справочник видов изделий (`GET /api/v1/product-types`, экран «Виды изделий», приставка `data-testid`
`pt`) с [тестовым набором][fixture] из 15 записей. Новый список добавляется строкой в примеры сценариев.

## FR-G-PAG-001. Постраничная выдача списка {#fr-g-pag-001 .collapsed}

- **Использует**: [SF-G-PAG][], [AR-001][]
- **Используется в**: [UI-G-PAG-001][], [FR-PT-LIST-001][]
- **Описание**: Операция списка возвращает одну страницу записей и общее количество записей, которые удовлетворяют
условиям запроса.
- **Условие**: Пользователь вызывает операцию списка, которая подключает [SF-G-PAG][]; проверки [AR-001][]
пройдены.
- **Результат**:
    - Параметр `page` — номер страницы, целое число от 1; по умолчанию 1.
    - Параметр `page_size` — количество записей на странице: 10, 25, 50 или 100 (см. `H01`); по умолчанию 10.
    - Ответ — объект с полями `items` (записи страницы в порядке, заданном [SF-G-SORT][]), `page`, `page_size` и
      `total` — количество записей, которые удовлетворяют поиску и фильтрам, на всех страницах.
    - Номер страницы больше последней — не ошибка: ответ `200` с пустым `items` и фактическим `total`.
    - Нет записей или ничего не найдено — ответ `200` с пустым `items` и `total` = 0.
    - Ошибки параметров (ответ `400`, коды из [AR-001][]):

| Параметр | Проверка | Код в `details` |
| :--- | :--- | :--- |
| `page` | Значение — целое число | `INVALID_TYPE` |
| `page` | Значение не меньше 1 | `OUT_OF_RANGE` |
| `page_size` | Значение — одно из 10, 25, 50, 100 | `INVALID_VALUE` |

- **Показатели (NFR)**: На странице не больше 100 записей. Время ответа задаёт функциональность, которая подключает
пагинацию, для своего объёма данных.
- **Схема**: определения `page`, `page_size`, `total` и конверта ответа `page_envelope` — в
`global/api/list.schema.json`; схемы операций списка ссылаются на них (`$ref`).

### Критерии приёмки (AC) {#fr-g-pag-001-ac .collapsed}

```gherkin
# language: ru
@FR-G-PAG-001 @SF-G-PAG
Функционал: Постраничная выдача списка

  Предыстория:
    Дано в справочнике видов изделий записи из файла "PT.fixture.json"
    И аутентифицированный пользователь с правом просмотра списка

  Структура сценария: Страница списка
    Когда он запрашивает "<операция>" с параметрами "<параметры>"
    Тогда код ответа равен 200
    И в ответе "page" равно <page>, "page_size" равно <size>, "total" равно <total>
    И "items" содержит <количество> записей

    Примеры:
      | операция                  | параметры            | page | size | total | количество |
      | GET /api/v1/product-types |                      | 1    | 10   | 15    | 10         |
      | GET /api/v1/product-types | page=2               | 2    | 10   | 15    | 5          |
      | GET /api/v1/product-types | page=3               | 3    | 10   | 15    | 0          |
      | GET /api/v1/product-types | page_size=25         | 1    | 25   | 15    | 15         |
      | GET /api/v1/product-types | page=2&page_size=100 | 2    | 100  | 15    | 0          |

  Структура сценария: Ошибка в параметре пагинации
    Когда он запрашивает "<операция>" с параметрами "<параметры>"
    Тогда код ответа равен 400
    И "details" содержит одну ошибку с полем "<поле>" и кодом "<код>"

    Примеры:
      | операция                  | параметры    | поле      | код           |
      | GET /api/v1/product-types | page=0       | page      | OUT_OF_RANGE  |
      | GET /api/v1/product-types | page=abc     | page      | INVALID_TYPE  |
      | GET /api/v1/product-types | page_size=20 | page_size | INVALID_VALUE |

  Сценарий: Пустой список
    Дано справочник видов изделий пуст
    Когда он запрашивает "GET /api/v1/product-types"
    Тогда код ответа равен 200
    И "items" пустой, "total" равно 0
```

### Допущения {#fr-g-pag-001-assumptions .collapsed}

- **FR-G-PAG-001.H01**
    - **Статус**: требует подтверждения
    - **Подтверждает**: владелец продукта
    - **Допущение**: Размеры страницы 10, 25, 50, 100 взяты со скриншота справочника видов изделий (дизайн-система
      выровнена по нему); нужно подтвердить, что размер 100 нужен.
