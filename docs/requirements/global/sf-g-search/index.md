## SF-G-SEARCH. Поиск {#sf-g-search .collapsed}

- **Статус**: анализ
- **Приоритет**: must
- **Стабильность**: высокая — поведение снято со скриншотов; открыт вопрос о равенстве «е» и «ё», отложенный
  вместе с уточнением терминов
- **Права доступа**: определяет операция списка, которая подключает функциональность
- **Использует**: [AR-001][], [SF-G-PAG][], [дизайн-система][design-system] (TextInput, EmptyState)
- **Используется в**: [SF-PT-LIST][]
- **Описание**: Единые правила быстрого поиска записей по вхождению строки: параметр поиска в API и поле поиска на
панели инструментов списка.
- **Границы**:
    - **Входит**: Параметр `search`, правила сравнения (регистр, пробелы, служебные символы), поле поиска с задержкой
      запроса и очисткой, состояние «Ничего не найдено».
    - **Не входит**: Перечень полей, по которым ищет поиск, и подпись поля — их задаёт функциональность; фильтры по
      отдельным полям ([SF-G-FILTER][]); полнотекстовый поиск с морфологией не используется.

### Состав требований {#sf-g-search-content .collapsed}

| Требование | Что описывает |
| :--- | :--- |
| [FR-G-SEARCH-001][] | Поиск по вхождению строки (API) |
| [UI-G-SEARCH-001][] | Поле поиска и состояние «Ничего не найдено» |

### Как подключить {#sf-g-search-usage .collapsed}

Функциональность, которая подключает поиск, указывает в своих требованиях:

- поля, по которым ищет поиск (обычно наименование);
- плейсхолдер поля: «Поиск по <полю>»;
- максимальную длину строки, если она отличается от 150 символов;
- приставку `data-testid` экрана.
