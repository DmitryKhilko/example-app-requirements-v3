# Применение UI-независимых Use Case при кодогенерации с помощью ИИ

**Да, но только в паре со спецификациями функций (`SF`).** Сам по себе UI-независимый Use Case — это отличный «дирижер»
для ИИ, но ему не хватает конкретики, чтобы написать готовый к продакшену код без додумывания.

Разберем подробно, как именно связка `UC + SF` работает при генерации кода нейросетью.

## Почему чистый UC полезен для ИИ

- **Понимание бизнес-контекста (User Flow):** ИИ видит полную картину. Он понимает, *зачем* нужен экран, какие шаги идут
  друг за другом, как связаны состояния (например, сброс поиска должен сохранять выбранную сортировку) и какие краевые
  случаи (альтернативные потоки) нужно обработать.
- **Генерация тестов (E2E и интеграционных):** UI-независимый UC идеально ложится в основу BDD-сценариев (Gherkin /
  Cucumber) и тестов на Playwright или Cypress. ИИ легко переводит шаги «Актор — Система» в тестовые кейсы.
- **Архитектура фронтенда и стейт-менеджмента:** Понимая поток событий, нейросеть лучше проектирует сторы (Redux, Pinia,
  Zustand) и логику переходов между компонентами.

## Чего ИИ не хватит в таком UC

Если скормить нейросети **только** абстрактный UC, она начнет «галлюцинировать» (додумывать детали на свой вкус). Она
сама придумает размер страницы (10 вместо 20), названия полей JSON, типы кнопок и тексты ошибок.

## Как работает идеальный промпт для кодогенерации

Ваша архитектура документации (`F → UC + SF`) идеально подходит для LLM. Чтобы ИИ сгенерировал точный код, ему нужно
передавать контекст слоями:

1. **Use Case (`UC`)** — задает **поведение и сценарий** (что и в каком порядке происходит).
2. **Спецификация функции (`SF`)** — задает **контракты и ограничения** (API-эндпоинты, поля БД, валидацию, размер
   пагинации `limit=20`, коды сообщений `MSG:country.list_empty`).
3. **Дизайн-система / UI-кит** — задает **внешний вид** (какие конкретно компоненты использовать: таблицу, инпут,
   тоггл).

## Вывод

Разделение на абстрактный `UC` и детальный `SF` защищает вас от дублирования. Когда вы меняете размер страницы с 20 на
50, вы правите **одно место** (файл `sf-list/index.md`), а не переписываете кучу сценариев. ИИ при генерации просто
берет актуальный `UC` для логики и актуальный `SF` для параметров.
